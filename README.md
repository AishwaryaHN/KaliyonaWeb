# Kaliyona

B.Ed LTA (Q.P. 30201) exam prep — question papers, full model answers, and **Backbencher Mode** visual revision.

## Stack

- Vite + React + TypeScript + Tailwind CSS v4

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

See [DEPLOY.md](./DEPLOY.md). Set the Vercel **Root Directory** to this folder if the git repo is a monorepo.
