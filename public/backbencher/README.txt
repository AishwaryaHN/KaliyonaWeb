Optional custom card art (e.g. from Figma Weave / Nano Banana):

Name each file exactly:
  {paperId}-q{questionNumber}-p{pointIndex}.webp

Examples:
  lta-2024-q10-p1.webp
  lta-2024-q10-p2.webp
  ...
  lta-2025-26-q15-p6.webp

If the file exists, Backbencher Mode shows the image on that card.
If missing, a unique built-in cartoon SVG is used instead.
